## 带走

1. **Embedding ≠ 对话模型**  
   `ov.conf` 的 `embedding.dense` 只来自 `openviking.embedding`（`baseUrl` / `model` / `apiKeyEnv`）。不再用默认聊天 Provider（如 DeepSeek）填 dense。

2. **启用 OV 三件套必填**  
   缺独立 Embedding 或 Key 解析失败 → `needs_config`。VLM 仍用对话默认 Provider + 可选 `vlmModel`。

3. **设置主区**  
   长期记忆分区直接配置 Embedding；密钥走 credentials / 环境变量（建议 `OPENVIKING_EMBEDDING_API_KEY`）。

```text
设置：Embedding 表单
    → PUT /config (openviking.embedding) + PUT /credentials
    → OpenVikingSupervisor → ov.conf dense ← 独立端点
对话：openviking__find / search → 真实 embedding API
```

## 迁移

升级后若曾启用 OV，会进入 `needs_config`（预期）。在设置 → 长期记忆补全 Embedding 并保存密钥后点重试。

旧扁平 `embeddingModel` 仅用于 UI 预填模型名，不能单独满足门控。

## 手工冒烟

- [ ] DeepSeek 对话 + 独立 OpenAI（或兼容）embedding → OV `ready`
- [ ] distill 写入后 `openviking__find` 不再报 embedding 404
- [ ] 清空 embedding → 启用 → `needs_config`，对话仍可用
