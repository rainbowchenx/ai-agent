# P0-T11 断点笔记

日期：2026-09-06

## 学习目标

UI 只是 `RunEvent` 的投影。换皮时只要还消费同一契约，`packages/core` / `packages/server` / `packages/shared` 不用动。

## 换 UI 时哪些文件应保持不动

| 保持不动 | 原因 |
|----------|------|
| `packages/shared` | HTTP/WS DTO 与 `RunEvent` 契约 |
| `packages/core` | Runner / Ports，不依赖 UI |
| `packages/server` | 装配、SQLite、`/sessions`、`/ws`、`POST /runs/:id/stop` |
| `packages/providers` / `packages/tools` | 模型与工具适配 |
| `apps/desktop/electron/**` | 壳与 preload；只暴露 `getServerBaseUrl()` |

可替换：`apps/desktop/src/components/**`、`src/App.tsx`、样式。应复用：`src/lib/ws-client.ts`、`src/lib/apply-run-event.ts`、`src/lib/api.ts`、`src/stores/session-store.ts`（或等价绑定）。

## 数据流

1. preload `getServerBaseUrl()` → 仅本机 HTTP/WS。  
2. `RunSocket` 连 `ws://…/ws`，`parseRunEvent` 后交给 `applyRunEvent`。  
3. Zustand `session-store` 持有 sessions + `RunProjection`。  
4. 停止不走 WS：`POST /runs/:runId/stop`，等 `run_end.reason=stopped`。

Renderer **禁止** 调模型、跑工具、读密钥。

## 自问

**换皮时内核为什么能不动？**  
视图只订阅 `RunEvent` 与 REST DTO。气泡/卡片是投影，不是执行器。

**重启后会话为什么还在？**  
Server SQLite 持久化；UI 启动时 `GET /sessions` 再 `GET /sessions/:id`。
