## Checkpoint 自问

**为什么 Server 不能进 `apps/desktop`？**  
Server 是持有会话与 Agent 编排的本机服务，应独立于 Electron 渲染进程；放进 desktop 会把传输层与 UI 生命周期绑死，也违反「Renderer 禁止直接调模型/工具」的边界。

**`packages/mcp` 现在为什么只有 README？**  
P0 聚焦自研 ReAct loop + OpenAI 兼容 Provider + 内置工具；MCP 实装排在 P2/P3，现仅预留目录与说明，避免 scope 膨胀。
