## 架构走读（带走）

1. **AGPL 可选旁路**  
   OpenViking 锁在 `packages/openviking-runtime`（uv + `pyproject.toml`），**不进** `packages/core`。默认关闭；启用即接受 AGPLv3 旁路组件。详见 `packages/openviking-runtime/README.md`。

2. **单一真相源**  
   「长期记忆」开关只改 `mcpServers.openviking.enabled`。Server 侧 `OpenVikingSupervisor` 在启用时 sync → 写 `ov.conf` → health/spawn → 补写 HTTP MCP 预设；关闭时只 kill **自有** child 并断开 MCP。

3. **先 OV 后 MCP，异步不堵 listen**  
   Supervisor reconcile 异步；外部已在 `127.0.0.1:1933` 健康则 `ownedProcess=false` 复用。工具名 `openviking__*`，权限 / Trace 与其它 MCP 同环。

```text
设置：长期记忆开关
    → PUT /config (mcpServers.openviking.enabled)
    → OpenVikingSupervisor.reconcile
        → uv sync / ov.conf / spawn|reuse → /health
        → 确保 MCP HTTP 预设 → McpSupervisor
    → GET /openviking/status · GET /mcp/status
对话：openviking__* → 工具卡 / 权限卡 / Trace (kind: tool)
```

## 最短试用路径

1. `pnpm ov:sync`（需本机 [uv](https://docs.astral.sh/uv/) + Python ≥ 3.11）。  
2. 启动 Server + Desktop；设置 → 模型与 Provider 填好密钥。  
3. 设置 → **长期记忆** → 启用 OpenViking → 等状态 `ready`（可点重试）。  
4. MCP 分区确认 `openviking` 就绪与工具列表。  
5. 新开对话，请模型调用 `openviking__health` 或检索类 `openviking__find`；核对工具卡与 Trace。  
6. 关闭开关，确认自有进程退出（`ownedProcess` 场景）；外部已起 OV 时进程应仍在。
