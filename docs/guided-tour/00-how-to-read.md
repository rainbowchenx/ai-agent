# 如何跟读本系列

本系列面向「一块一块」走读：先抓住**理念与分层**，再落到**具体文件与函数**，最后用自检问题验证是否真懂。

## 建议节奏

1. 先读本章对应正文，对照文中路径在编辑器里打开文件，不必一次读完所有实现细节。
2. 需要「Enter → tool_end」的 5 分钟快览时，打开 [`docs/learning/MAP.md`](../learning/MAP.md)，与本章分层图对照。
3. 设计意图、阶段边界以 [`docs/superpowers/specs/2026-09-05-agent-runtime-design.md`](../superpowers/specs/2026-09-05-agent-runtime-design.md) 为准；本系列**引用路径，不整篇复述规格**。
4. 每章末尾的「潜在问题」与「自检问题」适合口头讲解后当场讨论，不必先查答案。

## 文档分工（避免混淆）

| 文档族 | 用途 |
|--------|------|
| `docs/guided-tour/`（本系列） | 按块讲解：意图 → 路径 → 流 → 质疑点 |
| `docs/learning/` | 实现过程断点笔记、调用链地图、P0 验收 |
| `docs/superpowers/specs/`、`plans/` | 已确认规格与分阶段计划（大需求才走此流程） |

## 跟读姿势

- **产品视角**：问「用户从哪进、事件从哪出、失败如何收口」。
- **学习视角**：问「为何拆 Port、为何 Server 只做装配、扩展点空着会不会误导配置」。
- 本系列**只做走读**，不在此目录里顺手开新功能。
